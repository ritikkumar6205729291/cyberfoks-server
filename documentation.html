Phone Number Info

OSINT Tool

Get complete details of any Indian phone number including owner name, address, network circle and email.

How to Use:

  1. Navigate to the Phone Number Info page
  2. Enter a valid 10-digit Indian phone number
  3. Click on the "Initiate Scan" button
  4. Wait for the scanning animation to complete
  5. View the detailed results

Information You Get:

  • Owner Name
  • Father's Name
  • Full Address
  • Network Circle
  • Email Address
  • Aadhaar (if available)
  • Alternate Numbers
Pro Tip: For better results, use numbers that are active on Indian networks like Jio, Airtel, Vi or BSNL.

Vehicle Info

OSINT Tool

Lookup complete vehicle details from RC number - owner info, insurance, fitness, tax validity and more.

How to Use:

  1. Navigate to the Vehicle Info page
  2. Enter a valid RC number (e.g., BR02AF0245)
  3. Click on the "Initiate Scan" button
  4. Wait for the data to fetch
  5. View all vehicle details in organized cards

Information You Get:

  • Owner Name & Address
  • Vehicle Details (Maker, Model, Fuel)
  • Engine & Cubic Capacity
  • Insurance Details
  • Fitness & Tax Validity
  • Registration Date
  • RTO Information
Pro Tip: RC numbers follow a format like XX00XX0000 - state code, district code, series, and vehicle number.

Pincode Lookup

OSINT Tool

Find complete details of any Indian pincode - post offices, district, state and delivery status.

How to Use:

  1. Navigate to the Pincode Lookup page
  2. Enter a valid 6-digit Indian pincode (e.g., 804403)
  3. Click on the "Initiate Scan" button
  4. View detailed information about all post offices

Information You Get:

  • Post Office Name
  • District & State
  • Block & Division
  • Region & Circle
  • Delivery Status
  • Branch Type
Pro Tip: Indian pincodes start with digits 1-8 based on region - 1 for Delhi, 4 for Maharashtra, 8 for Bihar/Jharkhand, etc.

Temp Mail

Utility Tool

Generate temporary email addresses instantly - perfect for testing, verification and spam protection.

How to Use:

  1. Navigate to the Temp Mail page
  2. Click on "Generate Email" button
  3. Your temporary email address will appear
  4. Click the copy icon to copy the address
  5. Use it for any verification or signup
  6. Inbox auto-refreshes every second
  7. Click any message to read it

Features:

  • Instant email generation
  • 1-hour validity
  • Auto-refresh inbox (1 second)
  • Popup notifications for new emails
  • No registration required
  • Complete privacy & anonymity
Pro Tip: Use Temp Mail for OTP verification on websites you don't fully trust. Never use it for important accounts.
